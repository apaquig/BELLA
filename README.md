# BELLA — Plantilla Web

Plantilla web moderna, rápida y adaptable estilo BioLink / Pinterest, creada con **Astro 4.x** y **Vanilla CSS**.

## 🚀 Características

- 📱 **Diseño estilo app móvil**: Optimizado para la mejor experiencia en smartphones y escritorio.
- 🎨 **Estética Premium**: Efectos de glassmorphism, gradientes suaves, micro-animaciones y tema oscuro refinado.
- 🌐 **Soporte Multilingüe (i18n)**: Español e Inglés integrados con un solo clic.
- 🖼 **Placeholders Inteligentes**: No requiere imágenes locales previas. Cuenta con marcadores visuales estilizados listos para colocar tus fotos o enlaces de imagen.
- 🔞 **Modal de Advertencia 18+**: Sistema de verificación con desenfoque de contenido para enlaces de contenido exclusivo.
- ⚡ **Modales interactivos**: Modal "Próximamente" para tarjetas en desarrollo.

## 🛠️ Comandos

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build

# Vista previa de la compilación
npm run preview
```

## 📝 Personalización

Puedes personalizar el nombre, usuario y los textos en `src/layouts/Layout.astro` dentro del objeto `CONFIG` y `TRANSLATIONS`.

Para actualizar enlaces o fotos de tarjetas, edita los archivos en `src/components/`.
